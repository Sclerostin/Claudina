Your three questions

I saved the script. Why is nothing on the chart?

Saving and adding are two separate steps, and you need both. Saving stores the code in your TradingView account. If it saved without a red error message, the code compiled fine. Adding puts it on a chart:

On the chart, tap ƒx Indicators → Personal (some versions say My scripts) → tap DT Core. Its name appears in the top-left corner of the chart.

Added but still blank?

  • Daily chart. DT Core only draws on intraday charts. Switch to 5 minutes; the panel says so if you forget.
  • Indicator limit. The free plan fits very few indicators per chart. Remove Volume or anything else you're not using (tap its name → remove).
  • Hidden. Tap DT Core's name at the top left and make sure the eye icon is on.
  • Before the open or on a weekend. You'll see earlier days' lines and signals; today's start at 9:30.

What do "0930-1000" and "0930-0935" mean?

They were time windows on a 24-hour clock in New York time, written start-end without colons. Version 2 no longer asks for them: you pick Opening range length: Auto, 5, 15 or 30 minutes, and it measures from the opening bell on its own.

CodeClock timeMeaning
0930-09359:30 – 9:35 AMFirst 5 minutes after the open
0930-09459:30 – 9:45 AMFirst 15 minutes
0930-10009:30 – 10:00 AMFirst 30 minutes
1130-133011:30 AM – 1:30 PMThe midday lull, now shaded automatically

The chart settings didn't match my app.

Menus differ between app versions, and most of those settings didn't affect the signals. Version 2 handles timezone and pre-market data inside the script. The only chart settings you need: Candles, and the 5-minute timeframe.

To reach chart settings for anything else, long-press the price numbers on the right edge of the chart, then tap Settings.

Install or update

Four steps

  1. Copy DT Core. Use the Copy button below.
  2. Paste over the old version. Pine Editor → open your saved DT Core → select all → paste → Save. Keeping the name replaces the old code. No saved copy yet? Create a new indicator, paste, and save it as DT Core.
  3. Add it to the chart: ƒx Indicators → Personal → DT Core. If it's already on the chart, saving updates it in place.
  4. Set the chart to 5-minute candles, then enter your numbers. Tap DT Core's name on the chart → Settings → Risk and alerts: account size and risk per trade.

//@version=6
// ═══════════════════════════════════════════════════════════════════════════
//  DT Core 2 · simple BUY / SELL day-trading signals (uses ONE indicator slot)
//
//  The plan it follows for you (opening range breakout: Crabel 1990, Aziz 2015)
//   1. Wait for the opening range: the high and low of the first minutes after
//      the market opens. Auto picks 5, 15 or 30 minutes from your chart.
//   2. BUY when a candle CLOSES above the range, above VWAP, on strong volume.
//      SELL (short) is the mirror image below the range.
//   3. Stop at the middle of the range. Target = 2× what you risk.
//   4. Exit at the stop, the target, or 5 minutes before the close.
//      At most one BUY and one SELL per day; none after the cutoff.
//
//  Times are measured from the market open, so chart timezone and
//  extended-hours settings don't change the signals.
//  Educational tool. Not financial advice.
// ═══════════════════════════════════════════════════════════════════════════
indicator("DT Core", overlay = true, max_labels_count = 500, max_lines_count = 500)

float vol = nz(volume)
var float sPV  = 0.0
var float sV   = 0.0
var float sPV2 = 0.0

if vwapReset

// ───── Volume versus normal for this time of day ──────────────────────────

        float qtyIdea  = pos != 0 ? qty : not na(sizeRisk) and sizeRisk > 0 ? riskUsd / (sizeRisk * pv) : na
        row(4, "Size", na(qtyIdea) ? "—" : (pos == 0 ? "≈ " : "") + qtyStr(qtyIdea) + unit + " · risk $" + str.tostring(riskUsd, "#,##0"), fg)

        row(5, "Volume", na(rvol) ? (totVol == 0 ? "no volume data" : "building history") : str.tostring(rvol, "0.0") + "× normal" + (rvol >= 2 ? " · in play" : rvol < 1 ? " · quiet" : ""), na(rvol) ? fg : rvol >= 2 ? cBuy : fg)

        string score = nTrades == 0 ? "no trades yet on this chart" : str.tostring(nDays) + " days · " + str.tostring(nTrades) + " trades · " + str.tostring(nWins * 100.0 / nTrades, "0") + "% wins · " + (sumR >= 0 ? "+" : "") + str.tostring(sumR, "0.0") + "R"
        row(6, "Results", score, sumR > 0 ? cBuy : sumR < 0 ? cSell : fg)

Reading the signals

Labels appear when a candle closes and never move or disappear afterward.

  • BUYA candle closed above the opening range, above VWAP, on strong volume. Entry is that candle's closing price.
  • SELLThe mirror image below the range. SELL means sell short. If you only buy stocks, read it as "no longs today" or turn it off in settings.
  • Stop. Where the trade is wrong. Put this stop order in at your broker the moment you enter.
  • Target. Twice as far from entry as the stop, so a win pays 2× what a loss costs.
  • Entry price.
  • TARGET ✓Target hit: +2.0R. R means "times your risk". +2R on $125 risk is +$250.
  • STOP ✗Stop hit: −1.0R, a planned, limited loss.
  • EXITNeither was hit, so the trade closed 5 minutes before the market close.
  • VWAP, the day's average price weighted by volume. Green when price is above it (buyers in control), red when below.
  • Opening range. High and low of the first minutes after the open. Breakouts from this box are the signals.
  • Yesterday's high and low. Price often pauses here.
  • Pre-market high and low (overnight on futures). Shown even if your chart hides extended hours.
  • Midday, 2 to 4 hours after the open. Volume dries up and breakouts fail more often.

Hands-off

Alerts and automation

One alert per stock sends every BUY, SELL and exit to your phone with prices and share count.

  1. Open the stock's 5-minute chart. DT Core must be on it.
  2. Add an alert. Tap the alarm-clock button, or long-press the chart → Add alert.
  3. Condition: DT Core → Any alert() function call.
  4. Notify: app push on, sound on. Create.

What arrives on your phone:

BUY NVDA @ 102.00 · stop 100.75 · target 104.50 · 100 shares (risk $125) EXIT NVDA @ 104.50 · TARGET ✓ +2.0R

Change a setting and old alerts keep the old settings: delete and recreate them. iPhone: Settings → Notifications → TradingView → allow notifications and sounds, and keep it out of Scheduled Summary.

Three levels of automation

1
Alert → you place the order.

Works on any plan that includes indicator alerts. Copy the stop and target from the message into your order.

2
One bracket order at your broker.

Enter with a bracket (OCO) order: entry, stop and target in one ticket. The exit then happens without you, even if you look away. This is the biggest step toward hands-off trading and needs nothing extra.

3
Webhook → automation service → broker.

Needs a paid TradingView plan for webhooks. Set Alert message to JSON, paste the service's webhook URL into the alert, and it places orders for you. Run it on a paper account for weeks before real money.

{"action":"buy","ticker":"NVDA","price":102.00,"stop":100.75,"target":104.50,"qty":100} {"action":"exit","ticker":"NVDA","price":104.50,"reason":"target","r":2.00}
What it does, in order

The rules behind the signals

  1. Mark the opening range. The high and low of the first minutes after the open. Toby Crabel showed in 1990 that breakouts from it carry follow-through; Andrew Aziz teaches the same trade for stocks.
  2. Wait for a candle to close outside it. With strong volume, and on the side of VWAP that agrees (Shannon: VWAP is the day's fair price).
  3. Size from the stop. Stop at the middle of the range; shares = dollars at risk ÷ distance to the stop (Tharp).
  4. Let the trade end itself. Target at 2× risk, stop, or 5 minutes before the close. At most one BUY and one SELL a day, none after the cutoff.
  • 0.5–1% per tradeElder's ceiling is 2%. Start small while you learn.
  • Daily stop at −3RThree full losses and you're done for the day.
  • Paper trade firstRun 20 or more signals on TradingView's Paper Trading account before using real money. Many days produce no signal; that's by design.
  • Check your broker's rulesUS margin accounts face pattern-day-trader requirements.

DT Momentum · squeeze, 3/10 or RSI in one pane

Pick one oscillator under Settings → Oscillator. Squeeze (Carter): red dots mean energy is building; the first green dot is the release. 3/10 (Raschke) and RSI (Wilder) are the other choices.

DT_Momentum.pine · 95 lines

//@version=6
// ═══════════════════════════════════════════════════════════════════════════
//  DT Momentum · three classic day-trading oscillators in ONE pane
//  Squeeze  — John Carter, Mastering the Trade (Bollinger inside Keltner)
//  3/10     — Linda Bradford Raschke's 3/10 oscillator (SMA3 − SMA10, 16 signal)
//  RSI      — J. Welles Wilder, New Concepts in Technical Trading Systems
//  Pick one in settings; alerts follow the selected oscillator.
//  Educational tool. Not financial advice.
// ═══════════════════════════════════════════════════════════════════════════
indicator("DT Momentum", overlay = false, precision = 2)

string mode = input.string("Squeeze", "Oscillator", options = ["Squeeze", "3/10", "RSI"])

string G_SQ = "Squeeze (Carter)"
int   sqLen  = input.int(20, "Length", minval = 2, group = G_SQ)
float bbMult = input.float(2.0, "Bollinger σ", minval = 0.1, step = 0.1, group = G_SQ)
float kcMult = input.float(1.5, "Keltner ATR multiple", minval = 0.1, step = 0.1, group = G_SQ)

string G_310 = "3/10 oscillator (Raschke)"
int fastLen = input.int(3, "Fast SMA", minval = 1, group = G_310)
int slowLen = input.int(10, "Slow SMA", minval = 2, group = G_310)
int sigLen  = input.int(16, "Signal SMA", minval = 1, group = G_310)

string G_RSI = "RSI (Wilder)"
int   rsiLen = input.int(14, "Length", minval = 2, group = G_RSI)
float rsiHi  = input.float(70, "Overbought", minval = 50, maxval = 100, group = G_RSI)
float rsiLo  = input.float(30, "Oversold", minval = 0, maxval = 50, group = G_RSI)

string G_CL = "Colors"
color cUp   = input.color(#26a69a, "Up", inline = "c1", group = G_CL)
color cDn   = input.color(#ef5350, "Down", inline = "c1", group = G_CL)
color cSqz  = input.color(#ef5350, "Squeeze on", inline = "c2", group = G_CL)
color cFree = input.color(#26a69a, "Squeeze off", inline = "c2", group = G_CL)
color cLine = input.color(#42a5f5, "Line", inline = "c3", group = G_CL)
color cSig  = input.color(#f5a623, "Signal", inline = "c3", group = G_CL)

bool isSq  = mode == "Squeeze"
bool is310 = mode == "3/10"
bool isRsi = mode == "RSI"

// ───── Squeeze: Bollinger Bands inside Keltner Channels = volatility coiled ──
float basis = ta.sma(close, sqLen)
float bbDev = bbMult * ta.stdev(close, sqLen)
float kcDev = kcMult * ta.atr(sqLen)
bool  sqzOn = bbDev < kcDev
bool  sqzFired = sqzOn[1] and not sqzOn
float mom = ta.linreg(close - math.avg(math.avg(ta.highest(high, sqLen), ta.lowest(low, sqLen)), basis), sqLen, 0)
float momPrev = nz(mom[1])
color momCol = mom >= 0 ? (mom >= momPrev ? cUp : color.new(cUp, 60)) : (mom <= momPrev ? cDn : color.new(cDn, 60))

plot(isSq ? mom : na, "Squeeze momentum", momCol, 4, plot.style_columns)
plot(isSq ? 0.0 : na, "Squeeze state", sqzOn ? cSqz : cFree, 3, plot.style_circles)

// ───── 3/10 oscillator ────────────────────────────────────────────────────
float osc    = ta.sma(close, fastLen) - ta.sma(close, slowLen)
float oscSig = ta.sma(osc, sigLen)
plot(is310 ? osc - oscSig : na, "3/10 histogram", osc >= oscSig ? color.new(cUp, 70) : color.new(cDn, 70), 4, plot.style_columns)
plot(is310 ? osc : na, "3/10 fast line", cLine, 2)
plot(is310 ? oscSig : na, "3/10 slow line", cSig, 2)

// ───── RSI ────────────────────────────────────────────────────────────────
float rsi = ta.rsi(close, rsiLen)
plot(isRsi ? rsi : na, "RSI", cLine, 2)
hline(rsiHi, "Overbought", color.new(cDn, 40), hline.style_dashed, display = isRsi ? display.all : display.none)
hline(50, "Midline", color.new(color.gray, 50), hline.style_dotted, display = isRsi ? display.all : display.none)
hline(rsiLo, "Oversold", color.new(cUp, 40), hline.style_dashed, display = isRsi ? display.all : display.none)
hline(0, "Zero", color.new(color.gray, 60), hline.style_dotted, display = isRsi ? display.none : display.all)

// ───── Signals ────────────────────────────────────────────────────────────
bool x310Up = ta.crossover(osc, oscSig)
bool x310Dn = ta.crossunder(osc, oscSig)
bool xRsiUp = ta.crossover(rsi, rsiLo)
bool xRsiDn = ta.crossunder(rsi, rsiHi)

bool sqUp  = isSq and sqzFired and mom > 0
bool sqDn  = isSq and sqzFired and mom < 0
bool t3Up  = is310 and x310Up
bool t3Dn  = is310 and x310Dn
bool rsUp  = isRsi and xRsiUp
bool rsDn  = isRsi and xRsiDn

plotshape(sqUp or t3Up or rsUp, "Bullish trigger", shape.triangleup, location.bottom, cUp, size = size.tiny)
plotshape(sqDn or t3Dn or rsDn, "Bearish trigger", shape.triangledown, location.top, cDn, size = size.tiny)

// ───── Alerts ─────────────────────────────────────────────────────────────
string msg = sqUp ? "squeeze fired UP" : sqDn ? "squeeze fired DOWN" : t3Up ? "3/10 crossed above signal" : t3Dn ? "3/10 crossed below signal" : rsUp ? "RSI back above " + str.tostring(rsiLo) : rsDn ? "RSI back below " + str.tostring(rsiHi) : ""
if msg != ""
    alert(syminfo.ticker + " " + timeframe.period + ": " + msg + " · last " + str.tostring(close, format.mintick), alert.freq_once_per_bar_close)

alertcondition(sqUp, "Squeeze fired up", "{{ticker}} {{interval}}: squeeze fired UP at {{close}}")
alertcondition(sqDn, "Squeeze fired down", "{{ticker}} {{interval}}: squeeze fired DOWN at {{close}}")
alertcondition(t3Up, "3/10 bullish cross", "{{ticker}} {{interval}}: 3/10 oscillator crossed above its signal")
alertcondition(t3Dn, "3/10 bearish cross", "{{ticker}} {{interval}}: 3/10 oscillator crossed below its signal")
alertcondition(rsUp, "RSI leaves oversold", "{{ticker}} {{interval}}: RSI crossed back above oversold")
alertcondition(rsDn, "RSI leaves overbought", "{{ticker}} {{interval}}: RSI crossed back below overbought")
DT Volume · volume bars that light up on spikes

Replaces the built-in Volume. Bars at 2× the recent average print in full color.

DT_Volume.pine · 33 lines

//@version=6
// ═══════════════════════════════════════════════════════════════════════════
//  DT Volume · volume columns that light up on spikes
//  Replaces the built-in Volume indicator. Faded bars are ordinary volume;
//  full-color bars traded at least N× the recent average (institutional
//  participation; Aziz and Bellafiore look for it on breakouts).
//  Educational tool. Not financial advice.
// ═══════════════════════════════════════════════════════════════════════════
indicator("DT Volume", format = format.volume)

int   avgLen = input.int(20, "Average length", minval = 1)
float spikeX = input.float(2.0, "Spike threshold (× average)", minval = 1, step = 0.1)
color cUp    = input.color(#26a69a, "Up", inline = "c")
color cDn    = input.color(#ef5350, "Down", inline = "c")
color cAvg   = input.color(#f5a623, "Average", inline = "c")

float v     = nz(volume)
float vAvg  = ta.sma(v, avgLen)
bool  up    = close >= open
bool  spike = not na(vAvg) and vAvg > 0 and v >= spikeX * vAvg
color col   = spike ? (up ? cUp : cDn) : color.new(up ? cUp : cDn, 65)

plot(v, "Volume", col, style = plot.style_columns)
plot(vAvg, "Average", cAvg, 1)
plot(vAvg * spikeX, "Spike threshold", color.new(cAvg, 70), 1, display = display.none)

bool spikeUp = spike and up
bool spikeDn = spike and not up
if spike
    alert(syminfo.ticker + " " + timeframe.period + ": volume spike " + str.tostring(v / vAvg, "0.0") + "× average on a " + (up ? "green" : "red") + " bar · last " + str.tostring(close, format.mintick), alert.freq_once_per_bar_close)

alertcondition(spikeUp, "Volume spike on up bar", "{{ticker}} {{interval}}: volume spike on an up bar at {{close}}")
alertcondition(spikeDn, "Volume spike on down bar", "{{ticker}} {{interval}}: volume spike on a down bar at {{close}}")
