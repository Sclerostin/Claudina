Setup order

Start here

  1. Set the chart up first. Extended hours on, exchange timezone, right margin of about 10 bars. Chart settings
  2. Paste the scripts into the Pine Editor. Copy each one below, save it under its name, add it to the chart. Scripts
  3. Match the inputs to your timeframe. The opening range window changes with the chart you trade. Timeframes
  4. Create alerts from the chart you trade. One alert on DT Core covers every signal it draws. Alerts
  5. Paper trade the playbook for 20+ trades. TradingView's Paper Trading broker works in the iOS app. Keep a journal. Playbook

Pine Editor

The three scripts

  1. Tap Copy on a script below. If copying is blocked, the code gets selected instead; use the iOS Copy bubble.
  2. Open the Pine Editor from a chart in the TradingView app. Depending on app version it sits in the chart's bottom toolbar or under the ⋯ menu.
  3. Create a new indicator, select all of the template code, delete it, and paste.
  4. Save with the script's name (DT Core, DT Momentum, DT Volume), then Add to chart.

No Pine Editor in your app? Open tradingview.com in Safari, tap aA → Request Desktop Website, open a chart, and use the Pine Editor tab at the bottom. Saved scripts sync to your account and show up in the iOS app under Indicators → My scripts.

DT Core

overlay · 399 lines

The whole intraday map in one indicator slot.

  • Session VWAP with volume-weighted ±1σ and ±2σ bands; anchor at the session or at the 9:30 open
  • 9 and 20 EMA, 200 SMA
  • Opening range box with optional 1× and 2× measured-move targets
  • Prior-day high, low and close; pre-market high and low (overnight high/low on futures); central pivot range
  • Dashboard: bias, time-of-day relative volume, gap, share of daily ATR used, and position size for your stop
  • Signals: ORB (volume and VWAP filtered, once per day each side), PDH/PDL breaks, VWAP reclaim/loss, EMA cross, ±2σ stretch
DT_Core.pine

//@version=6
// ═══════════════════════════════════════════════════════════════════════════
//  DT Core · all-in-one intraday overlay (uses ONE indicator slot)
//  VWAP ±σ · 9/20 EMA · 200 SMA · Opening range · Prior-day H/L/C
//  Pre-open H/L · Central pivot range · Time-of-day RVOL · R-based sizing
//
//  Methods: Crabel (opening range breakout), Shannon & Aziz (VWAP, 9/20 EMA),
//  Fisher & Ochoa (pivot range), Bellafiore (stocks in play / RVOL),
//  Tharp & Elder (fixed-fractional risk, R-multiples).
//  Educational tool. Not financial advice.
// ═══════════════════════════════════════════════════════════════════════════
indicator("DT Core", overlay = true, max_labels_count = 50)

// ───── Inputs ─────────────────────────────────────────────────────────────

string orSess    = input.session("0930-0945", "Opening range", group = G_SES, tooltip = "Crabel / Aziz ORB. 0930-0935 = 5-min, 0930-0945 = 15-min, 0930-1000 = 30-min. Use a chart timeframe no larger than the range.")
string sigSess   = input.session("0930-1130", "Breakout signal window", group = G_SES, tooltip = "ORB signals only fire inside this window. Opening-range breakouts lose their edge after the morning session.")
bool   shadeLunch = input.bool(true, "Shade midday chop", inline = "lunch", group = G_SES)
string lunchSess = input.session("1130-1330", "", inline = "lunch", group = G_SES)

string G_VW = "VWAP"

string vwapAnchor = input.string("Session", "Anchor", options = ["Session", "RTH open"], group = G_VW, tooltip = "Session: resets at the start of the trading day (includes pre-market when Extended hours is on). RTH open: resets at the start of the opening range.")
bool   showBand1  = input.bool(true, "Inner band", inline = "b1", group = G_VW)
float  band1Mult  = input.float(1.0, "inner σ", minval = 0.1, step = 0.1, inline = "b1", group = G_VW)
bool   showBand2  = input.bool(true, "Outer band", inline = "b2", group = G_VW)
float  band2Mult  = input.float(2.0, "outer σ", minval = 0.1, step = 0.1, inline = "b2", group = G_VW)

string G_MA = "Moving averages"
bool showFast  = input.bool(true, "Fast EMA", inline = "f", group = G_MA)
int  fastLen   = input.int(9, "", minval = 1, inline = "f", group = G_MA)
bool showSlow  = input.bool(true, "Slow EMA", inline = "s", group = G_MA)
int  slowLen   = input.int(20, "", minval = 1, inline = "s", group = G_MA)
bool showTrend = input.bool(true, "Trend SMA", inline = "t", group = G_MA)
int  trendLen  = input.int(200, "", minval = 1, inline = "t", group = G_MA)

string G_LV = "Key levels"
bool showOR   = input.bool(true, "Opening range", group = G_LV)
bool showORX  = input.bool(false, "OR measured-move targets (1× and 2×)", group = G_LV)
bool showPD   = input.bool(true, "Prior day high / low / close", group = G_LV)
bool showPM   = input.bool(true, "Pre-open high / low (pre-market or overnight)", group = G_LV, tooltip = "High and low of the bars between the start of the trading day and the opening range. Stocks need Extended hours on.")
bool showCPR  = input.bool(false, "Central pivot range", group = G_LV, tooltip = "Fisher (The Logical Trader) / Ochoa (Secrets of a Pivot Boss). A narrow range often precedes a trend day.")
bool showTags = input.bool(true, "Price tags on the right edge", group = G_LV)

string G_SG = "Signals and alerts"
bool  sigORB  = input.bool(true, "Opening range breakout", group = G_SG)
bool  fVwap   = input.bool(true, "ORB must agree with VWAP side", group = G_SG)
float volMult = input.float(1.5, "ORB minimum volume (× 20-bar average)", minval = 0, step = 0.1, group = G_SG, tooltip = "0 turns the volume filter off.")
bool  sigPD   = input.bool(true, "Prior-day high / low break", group = G_SG)
bool  sigVWAP = input.bool(false, "VWAP reclaim / loss", group = G_SG)
bool  sigEMA  = input.bool(false, "Fast / slow EMA cross", group = G_SG)
bool  sigExt  = input.bool(false, "Outer-band stretch (don't chase)", group = G_SG)

string G_RK = "Dashboard and risk"
bool   showDash = input.bool(true, "Show dashboard", group = G_RK)
string dashPos  = input.string("Top right", "Position", options = ["Top right", "Bottom right", "Bottom left", "Top left"], group = G_RK)
float  acct     = input.float(25000, "Account size", minval = 0, group = G_RK)
float  riskPct  = input.float(0.5, "Risk per trade (%)", minval = 0.01, step = 0.05, group = G_RK, tooltip = "Tharp / Elder: risk a small fixed fraction per trade. 0.5–1% is common; 2% is Elder's ceiling.")
string stopMode = input.string("ATR", "Stop basis", options = ["ATR", "Opening range", "VWAP"], group = G_RK)
float  atrMult  = input.float(1.5, "ATR multiple (chart timeframe)", minval = 0.1, step = 0.1, group = G_RK)
int    rvolDays = input.int(10, "RVOL lookback (days)", minval = 2, maxval = 50, group = G_RK)

string G_CL = "Colors"
color cBull  = input.color(#26a69a, "Bull", inline = "c1", group = G_CL)
color cBear  = input.color(#ef5350, "Bear", inline = "c1", group = G_CL)
color cVwap  = input.color(#f5a623, "VWAP", inline = "c1", group = G_CL)
color cFast  = input.color(#42a5f5, "Fast", inline = "c2", group = G_CL)
color cSlow  = input.color(#ab47bc, "Slow", inline = "c2", group = G_CL)
color cTrend = input.color(#9e9e9e, "Trend", inline = "c2", group = G_CL)
color cOR    = input.color(#29b6f6, "OR", inline = "c3", group = G_CL)
color cPD    = input.color(#ffca28, "Prior day", inline = "c3", group = G_CL)
color cPM    = input.color(#b0bec5, "Pre-open", inline = "c3", group = G_CL)
color cCPR   = input.color(#7e57c2, "CPR", inline = "c4", group = G_CL)

// ───── Session state ──────────────────────────────────────────────────────
bool intra   = timeframe.isintraday
bool newDay  = timeframe.change("D")
bool inOR    = not na(time(timeframe.period, orSess, tz))
bool inSig   = not na(time(timeframe.period, sigSess, tz))
bool inLunch = not na(time(timeframe.period, lunchSess, tz))
bool inMkt   = session.ismarket
float vol    = nz(volume)

// Opening range, pre-open range and regular-session day stats
var float orH    = na
var float orL    = na
var bool  orSeen = false
var bool  orDone = false
var float pmH    = na
var float pmL    = na
var float dayO   = na
var float dayH   = na
var float dayL   = na

if newDay
    orH    := na
    orL    := na
    orSeen := false
    orDone := false
    pmH    := na
    pmL    := na
    dayO   := na
    dayH   := na
    dayL   := na

bool orStart = inOR and not orSeen
if inOR
    orH    := na(orH) ? high : math.max(orH, high)
    orL    := na(orL) ? low : math.min(orL, low)
    orSeen := true
else if orSeen
    orDone := true

if not orSeen
    pmH := na(pmH) ? high : math.max(pmH, high)
    pmL := na(pmL) ? low : math.min(pmL, low)

if orStart
    dayO := open
    dayH := high
    dayL := low
else if orSeen and inMkt
    dayH := math.max(dayH, high)
    dayL := math.min(dayL, low)

float orRange = orH - orL

// ───── VWAP with volume-weighted σ bands ──────────────────────────────────
var float sPV  = 0.0
var float sV   = 0.0
var float sPV2 = 0.0
bool vwapReset = newDay or (vwapAnchor == "RTH open" and orStart)
if vwapReset
    sPV  := 0.0
    sV   := 0.0
    sPV2 := 0.0
sPV  += hlc3 * vol
sV   += vol
sPV2 += hlc3 * hlc3 * vol
float vwapVal = sV > 0 ? sPV / sV : na
float sd      = sV > 0 ? math.sqrt(math.max(sPV2 / sV - vwapVal * vwapVal, 0.0)) : na
float up1 = vwapVal + band1Mult * sd
float dn1 = vwapVal - band1Mult * sd
float up2 = vwapVal + band2Mult * sd
float dn2 = vwapVal - band2Mult * sd

// ───── Moving averages, ATR, volume ───────────────────────────────────────
float emaFast  = ta.ema(close, fastLen)
float emaSlow  = ta.ema(close, slowLen)
float smaTrend = ta.sma(close, trendLen)
float atrTF    = ta.atr(14)
float volAvg   = ta.sma(vol, 20)
bool  volOK    = volMult <= 0 or na(volAvg) or volAvg == 0 or vol >= volMult * volAvg

// ───── Prior-day levels and daily ATR (regular session, no repaint) ───────
string dailyId = ticker.modify(syminfo.tickerid, session.regular)
[pdh, pdl, pdc, dAtr] = request.security(dailyId, "D", [high[1], low[1], close[1], ta.atr(14)[1]], lookahead = barmerge.lookahead_on)

float cprP   = (pdh + pdl + pdc) / 3
float cprBC  = (pdh + pdl) / 2
float cprTC  = 2 * cprP - cprBC
float cprTop = math.max(cprTC, cprBC)
float cprBot = math.min(cprTC, cprBC)

// ───── Time-of-day relative volume ────────────────────────────────────────
// Today's cumulative volume divided by the average cumulative volume at the
// same clock time over the last N sessions.
type VolHist
    array<float> vals

var map<int, VolHist> volByTime = map.new<int, VolHist>()
var float cumVol = 0.0
if newDay
    cumVol := 0.0
cumVol += vol

bool  rvolOn = intra and timeframe.in_seconds() >= 60
int   todKey = hour * 60 + minute
float avgCum = na
if rvolOn and map.contains(volByTime, todKey)
    VolHist h = map.get(volByTime, todKey)
    if array.size(h.vals) > 0
        avgCum := array.avg(h.vals)
float rvol = not na(avgCum) and avgCum > 0 ? cumVol / avgCum : na

if rvolOn and barstate.isconfirmed
    if not map.contains(volByTime, todKey)
        map.put(volByTime, todKey, VolHist.new(array.new<float>()))
    VolHist hh = map.get(volByTime, todKey)
    array.push(hh.vals, cumVol)
    if array.size(hh.vals) > rvolDays
        array.shift(hh.vals)

// ───── Signals (computed every bar, confirmed at bar close by the alert) ──
bool xUpOR  = ta.crossover(close, orH)
bool xDnOR  = ta.crossunder(close, orL)
bool xUpVW  = ta.crossover(close, vwapVal)
bool xDnVW  = ta.crossunder(close, vwapVal)
bool xUpPDH = ta.crossover(close, pdh)
bool xDnPDL = ta.crossunder(close, pdl)
bool xUpEMA = ta.crossover(emaFast, emaSlow)
bool xDnEMA = ta.crossunder(emaFast, emaSlow)
bool xUpExt = ta.crossover(close, up2)
bool xDnExt = ta.crossunder(close, dn2)

var bool orbLongDone  = false
var bool orbShortDone = false
if newDay
    orbLongDone  := false
    orbShortDone := false

bool vwapLongOK  = not fVwap or na(vwapVal) or close > vwapVal
bool vwapShortOK = not fVwap or na(vwapVal) or close < vwapVal
bool orbLong  = intra and sigORB and orDone and inSig and xUpOR and volOK and vwapLongOK and not orbLongDone
bool orbShort = intra and sigORB and orDone and inSig and xDnOR and volOK and vwapShortOK and not orbShortDone
if orbLong
    orbLongDone := true
if orbShort
    orbShortDone := true

bool pdhBreak = intra and sigPD and inMkt and xUpPDH
bool pdlBreak = intra and sigPD and inMkt and xDnPDL
bool vwapUp   = intra and sigVWAP and inMkt and not vwapReset and xUpVW
bool vwapDn   = intra and sigVWAP and inMkt and not vwapReset and xDnVW
bool emaUp    = intra and sigEMA and xUpEMA
bool emaDn    = intra and sigEMA and xDnEMA
bool extUp    = intra and sigExt and inMkt and not vwapReset and xUpExt
bool extDn    = intra and sigExt and inMkt and not vwapReset and xDnExt

// ───── Plots ──────────────────────────────────────────────────────────────
bool vwOn = intra and showVwap
pVw  = plot(vwOn and not vwapReset ? vwapVal : na, "VWAP", cVwap, 2, plot.style_linebr)
pU1  = plot(vwOn and showBand1 and not vwapReset ? up1 : na, "VWAP upper inner", color.new(cVwap, 55), 1, plot.style_linebr)
pD1  = plot(vwOn and showBand1 and not vwapReset ? dn1 : na, "VWAP lower inner", color.new(cVwap, 55), 1, plot.style_linebr)
pU2  = plot(vwOn and showBand2 and not vwapReset ? up2 : na, "VWAP upper outer", color.new(cBear, 45), 1, plot.style_linebr)
pD2  = plot(vwOn and showBand2 and not vwapReset ? dn2 : na, "VWAP lower outer", color.new(cBull, 45), 1, plot.style_linebr)
fill(pU1, pD1, color.new(cVwap, 93), "VWAP inner fill")

plot(showFast ? emaFast : na, "Fast EMA", cFast, 1)
plot(showSlow ? emaSlow : na, "Slow EMA", cSlow, 2)
plot(showTrend ? smaTrend : na, "Trend SMA", cTrend, 2)

pOH = plot(intra and showOR ? orH : na, "OR high", cOR, 2, plot.style_linebr)
pOL = plot(intra and showOR ? orL : na, "OR low", cOR, 2, plot.style_linebr)
fill(pOH, pOL, color.new(cOR, 90), "OR fill")
plot(intra and showORX and orDone ? orH + orRange : na, "OR target +1×", color.new(cOR, 30), 1, plot.style_circles)
plot(intra and showORX and orDone ? orH + 2 * orRange : na, "OR target +2×", color.new(cOR, 30), 1, plot.style_circles)
plot(intra and showORX and orDone ? orL - orRange : na, "OR target −1×", color.new(cOR, 30), 1, plot.style_circles)
plot(intra and showORX and orDone ? orL - 2 * orRange : na, "OR target −2×", color.new(cOR, 30), 1, plot.style_circles)

plot(intra and showPD and not newDay ? pdh : na, "Prior day high", cPD, 1, plot.style_linebr)
plot(intra and showPD and not newDay ? pdl : na, "Prior day low", cPD, 1, plot.style_linebr)
plot(intra and showPD and not newDay ? pdc : na, "Prior day close", color.new(cPD, 40), 1, plot.style_circles)

plot(intra and showPM ? pmH : na, "Pre-open high", cPM, 1, plot.style_linebr)
plot(intra and showPM ? pmL : na, "Pre-open low", cPM, 1, plot.style_linebr)

pCT = plot(intra and showCPR and not newDay ? cprTop : na, "CPR top", color.new(cCPR, 30), 1, plot.style_linebr)
pCB = plot(intra and showCPR and not newDay ? cprBot : na, "CPR bottom", color.new(cCPR, 30), 1, plot.style_linebr)
fill(pCT, pCB, color.new(cCPR, 85), "CPR fill")

bgcolor(intra and shadeLunch and inLunch ? color.new(color.gray, 92) : na, title = "Midday chop")

plotshape(orbLong, "ORB long", shape.triangleup, location.belowbar, cBull, text = "ORB", textcolor = cBull, size = size.small)
plotshape(orbShort, "ORB short", shape.triangledown, location.abovebar, cBear, text = "ORB", textcolor = cBear, size = size.small)
plotshape(pdhBreak, "PDH break", shape.diamond, location.belowbar, cPD, text = "PDH", textcolor = cPD, size = size.tiny)
plotshape(pdlBreak, "PDL break", shape.diamond, location.abovebar, cPD, text = "PDL", textcolor = cPD, size = size.tiny)
plotshape(vwapUp, "VWAP reclaim", shape.circle, location.belowbar, cVwap, text = "VW", textcolor = cVwap, size = size.tiny)
plotshape(vwapDn, "VWAP loss", shape.circle, location.abovebar, cVwap, text = "VW", textcolor = cVwap, size = size.tiny)
plotshape(emaUp, "EMA cross up", shape.arrowup, location.belowbar, cFast, size = size.tiny)
plotshape(emaDn, "EMA cross down", shape.arrowdown, location.abovebar, cFast, size = size.tiny)
plotshape(extUp, "Stretch above outer band", shape.xcross, location.abovebar, cBear, text = "2σ", textcolor = cBear, size = size.tiny)
plotshape(extDn, "Stretch below outer band", shape.xcross, location.belowbar, cBull, text = "2σ", textcolor = cBull, size = size.tiny)

// ───── Right-edge price tags ──────────────────────────────────────────────
addTag(array<label> arr, float y, string name, color col) =>
    if not na(y)
        array.push(arr, label.new(bar_index + 3, y, name + " " + str.tostring(y, format.mintick), style = label.style_label_left, color = color.new(col, 100), textcolor = col, size = size.small))

var array<label> tags = array.new<label>()
if barstate.islast
    for l in tags
        label.delete(l)
    array.clear(tags)
    if intra and showTags
        if showVwap
            addTag(tags, vwapVal, "VWAP", cVwap)
        if showOR and orDone
            addTag(tags, orH, "ORH", cOR)
            addTag(tags, orL, "ORL", cOR)
        if showPD
            addTag(tags, pdh, "PDH", cPD)
            addTag(tags, pdl, "PDL", cPD)
        if showPM
            addTag(tags, pmH, "PMH", cPM)
            addTag(tags, pmL, "PML", cPM)

// ───── Dashboard ──────────────────────────────────────────────────────────
posOf(string p) =>
    switch p
        "Top left"     => position.top_left
        "Bottom left"  => position.bottom_left
        "Bottom right" => position.bottom_right
        => position.top_right

float riskUsd = acct * riskPct / 100
float pv      = syminfo.pointvalue
float stopL = switch stopMode
    "Opening range" => orL
    "VWAP"          => vwapVal
    => close - atrMult * atrTF
float stopS = switch stopMode
    "Opening range" => orH
    "VWAP"          => vwapVal
    => close + atrMult * atrTF
float distL = close - stopL
float distS = stopS - close
float qtyL  = not na(distL) and distL > 0 ? riskUsd / (distL * pv) : na
float qtyS  = not na(distS) and distS > 0 ? riskUsd / (distS * pv) : na
bool  fracQty = syminfo.type == "crypto" or syminfo.type == "forex"
string unit   = syminfo.type == "futures" ? " ct" : fracQty ? " units" : " sh"

qtyText(float q, float stop) =>
    na(q) ? "stop on wrong side" : "stop " + str.tostring(stop, format.mintick) + " · " + (fracQty ? str.tostring(q, "0.####") : str.tostring(math.floor(q))) + unit

var table dash = table.new(posOf(dashPos), 2, 9, bgcolor = color.new(chart.bg_color, 8), border_color = color.new(chart.fg_color, 85), border_width = 1)

row(int r, string k, string v, color vc) =>
    table.cell(dash, 0, r, k, text_color = color.new(chart.fg_color, 30), text_size = size.small, text_halign = text.align_left)
    table.cell(dash, 1, r, v, text_color = vc, text_size = size.small, text_halign = text.align_right)

if barstate.islast and showDash
    color fg = chart.fg_color
    row(0, "DT Core", syminfo.ticker + " · " + timeframe.period, fg)
    if not intra
        row(1, "Timeframe", "use an intraday chart (1–15 min)", cBear)
    else
        bool aboveV = not na(vwapVal) and close > vwapVal
        bool belowV = not na(vwapVal) and close < vwapVal
        bool emaBull = emaFast > emaSlow
        string biasTxt = (na(vwapVal) ? "no volume" : aboveV ? "above VWAP" : "below VWAP") + " · " + str.tostring(fastLen) + (emaBull ? " > " : " < ") + str.tostring(slowLen)
        color biasCol = aboveV and emaBull ? cBull : belowV and not emaBull ? cBear : fg
        row(1, "Bias", biasTxt, biasCol)

        string rvTxt = na(rvol) ? "no history yet" : str.tostring(rvol, "0.00") + "×" + (rvol >= 2 ? "  in play" : "")
        color rvCol = na(rvol) ? fg : rvol >= 2 ? cBull : rvol >= 1 ? fg : color.new(fg, 45)
        row(2, "RVOL (time of day)", rvTxt, rvCol)

        float gapRef = na(dayO) ? close : dayO
        float gap = not na(pdc) and pdc > 0 ? (gapRef - pdc) / pdc * 100 : na
        string gapTxt = na(gap) ? "—" : (gap >= 0 ? "+" : "") + str.tostring(gap, "0.00") + "%" + (na(dayO) ? " pre-open" : "")
        row(3, "Gap vs prior close", gapTxt, na(gap) ? fg : gap >= 0 ? cBull : cBear)

        float used = na(dayH) or na(dAtr) or dAtr == 0 ? na : (dayH - dayL) / dAtr * 100
        string atrTxt = na(dAtr) ? "—" : str.tostring(dAtr, format.mintick) + (na(used) ? "" : " · " + str.tostring(used, "0") + "% used")

DT Momentum

pane · 95 lines

One pane, three oscillators. Pick one under Settings → Oscillator.

  • Squeeze (Carter): red dots mean Bollinger Bands sit inside the Keltner Channel and volatility is coiled. The first green dot is the "fire"; trade in the direction of the histogram.
  • 3/10 (Raschke): SMA(3) − SMA(10) with a 16-period signal line. In a trend, the first cross back in the trend's direction after a pullback is the entry.
  • RSI (Wilder): 14-period with 70/30. Alerts fire when RSI leaves an extreme, not when it enters one.
DT_Momentum.pine

//@version=6
// ═══════════════════════════════════════════════════════════════════════════
//  DT Momentum · three classic day-trading oscillators in ONE pane
//  Squeeze  — John Carter, Mastering the Trade (Bollinger inside Keltner)
//  3/10     — Linda Bradford Raschke's 3/10 oscillator (SMA3 − SMA10, 16 signal)
//  RSI      — J. Welles Wilder, New Concepts in Technical Trading Systems
//  Pick one in settings; alerts follow the selected oscillator.
//  Educational tool. Not financial advice.
// ═══════════════════════════════════════════════════════════════════════════
indicator("DT Momentum", overlay = false, precision = 2)

string mode = input.string("Squeeze", "Oscillator", options = ["Squeeze", "3/10", "RSI"])

string G_SQ = "Squeeze (Carter)"
int   sqLen  = input.int(20, "Length", minval = 2, group = G_SQ)
float bbMult = input.float(2.0, "Bollinger σ", minval = 0.1, step = 0.1, group = G_SQ)
float kcMult = input.float(1.5, "Keltner ATR multiple", minval = 0.1, step = 0.1, group = G_SQ)

string G_310 = "3/10 oscillator (Raschke)"
int fastLen = input.int(3, "Fast SMA", minval = 1, group = G_310)
int slowLen = input.int(10, "Slow SMA", minval = 2, group = G_310)
int sigLen  = input.int(16, "Signal SMA", minval = 1, group = G_310)

string G_RSI = "RSI (Wilder)"
int   rsiLen = input.int(14, "Length", minval = 2, group = G_RSI)
float rsiHi  = input.float(70, "Overbought", minval = 50, maxval = 100, group = G_RSI)
float rsiLo  = input.float(30, "Oversold", minval = 0, maxval = 50, group = G_RSI)

string G_CL = "Colors"
color cUp   = input.color(#26a69a, "Up", inline = "c1", group = G_CL)
color cDn   = input.color(#ef5350, "Down", inline = "c1", group = G_CL)
color cSqz  = input.color(#ef5350, "Squeeze on", inline = "c2", group = G_CL)
color cFree = input.color(#26a69a, "Squeeze off", inline = "c2", group = G_CL)
color cLine = input.color(#42a5f5, "Line", inline = "c3", group = G_CL)
color cSig  = input.color(#f5a623, "Signal", inline = "c3", group = G_CL)

bool isSq  = mode == "Squeeze"
bool is310 = mode == "3/10"
bool isRsi = mode == "RSI"

// ───── Squeeze: Bollinger Bands inside Keltner Channels = volatility coiled ──
float basis = ta.sma(close, sqLen)
float bbDev = bbMult * ta.stdev(close, sqLen)
float kcDev = kcMult * ta.atr(sqLen)
bool  sqzOn = bbDev < kcDev
bool  sqzFired = sqzOn[1] and not sqzOn
float mom = ta.linreg(close - math.avg(math.avg(ta.highest(high, sqLen), ta.lowest(low, sqLen)), basis), sqLen, 0)
float momPrev = nz(mom[1])
color momCol = mom >= 0 ? (mom >= momPrev ? cUp : color.new(cUp, 60)) : (mom <= momPrev ? cDn : color.new(cDn, 60))

plot(isSq ? mom : na, "Squeeze momentum", momCol, 4, plot.style_columns)
plot(isSq ? 0.0 : na, "Squeeze state", sqzOn ? cSqz : cFree, 3, plot.style_circles)

// ───── 3/10 oscillator ────────────────────────────────────────────────────
float osc    = ta.sma(close, fastLen) - ta.sma(close, slowLen)
float oscSig = ta.sma(osc, sigLen)
plot(is310 ? osc - oscSig : na, "3/10 histogram", osc >= oscSig ? color.new(cUp, 70) : color.new(cDn, 70), 4, plot.style_columns)
plot(is310 ? osc : na, "3/10 fast line", cLine, 2)
plot(is310 ? oscSig : na, "3/10 slow line", cSig, 2)

// ───── RSI ────────────────────────────────────────────────────────────────
float rsi = ta.rsi(close, rsiLen)
plot(isRsi ? rsi : na, "RSI", cLine, 2)
hline(rsiHi, "Overbought", color.new(cDn, 40), hline.style_dashed, display = isRsi ? display.all : display.none)
hline(50, "Midline", color.new(color.gray, 50), hline.style_dotted, display = isRsi ? display.all : display.none)
hline(rsiLo, "Oversold", color.new(cUp, 40), hline.style_dashed, display = isRsi ? display.all : display.none)
hline(0, "Zero", color.new(color.gray, 60), hline.style_dotted, display = isRsi ? display.none : display.all)

// ───── Signals ────────────────────────────────────────────────────────────
bool x310Up = ta.crossover(osc, oscSig)
bool x310Dn = ta.crossunder(osc, oscSig)
bool xRsiUp = ta.crossover(rsi, rsiLo)
bool xRsiDn = ta.crossunder(rsi, rsiHi)

bool sqUp  = isSq and sqzFired and mom > 0
bool sqDn  = isSq and sqzFired and mom < 0
bool t3Up  = is310 and x310Up
bool t3Dn  = is310 and x310Dn
bool rsUp  = isRsi and xRsiUp
bool rsDn  = isRsi and xRsiDn

plotshape(sqUp or t3Up or rsUp, "Bullish trigger", shape.triangleup, location.bottom, cUp, size = size.tiny)
plotshape(sqDn or t3Dn or rsDn, "Bearish trigger", shape.triangledown, location.top, cDn, size = size.tiny)

// ───── Alerts ─────────────────────────────────────────────────────────────
string msg = sqUp ? "squeeze fired UP" : sqDn ? "squeeze fired DOWN" : t3Up ? "3/10 crossed above signal" : t3Dn ? "3/10 crossed below signal" : rsUp ? "RSI back above " + str.tostring(rsiLo) : rsDn ? "RSI back below " + str.tostring(rsiHi) : ""
if msg != ""
    alert(syminfo.ticker + " " + timeframe.period + ": " + msg + " · last " + str.tostring(close, format.mintick), alert.freq_once_per_bar_close)

alertcondition(sqUp, "Squeeze fired up", "{{ticker}} {{interval}}: squeeze fired UP at {{close}}")
alertcondition(sqDn, "Squeeze fired down", "{{ticker}} {{interval}}: squeeze fired DOWN at {{close}}")
alertcondition(t3Up, "3/10 bullish cross", "{{ticker}} {{interval}}: 3/10 oscillator crossed above its signal")
alertcondition(t3Dn, "3/10 bearish cross", "{{ticker}} {{interval}}: 3/10 oscillator crossed below its signal")
alertcondition(rsUp, "RSI leaves oversold", "{{ticker}} {{interval}}: RSI crossed back above oversold")
alertcondition(rsDn, "RSI leaves overbought", "{{ticker}} {{interval}}: RSI crossed back below overbought")

//@version=6

//  DT Volume · volume columns that light up on spikes
//  Replaces the built-in Volume indicator. Faded bars are ordinary volume;
//  full-color bars traded at least N× the recent average (institutional

bool spikeDn = spike and not up

Playbook

Six setups DT Core is built to show

Only trade stocks in play: a catalyst, a gap, and time-of-day RVOL of 2× or more on the dashboard (Bellafiore, Aziz). Everything below assumes that filter.

Opening range breakout

long / short
Trigger
ORB marker: a candle closes beyond the range on 1.5× volume, on the matching side of VWAP.
Stop
Other side of the range, or its midpoint for half the risk.
Target
1× range (measured move), then 2× or the next level (PDH, PMH).
Skip
The dashboard shows most of the daily ATR already used, or the clock is past 11:30.

Crabel, 1990; Aziz, 2015

VWAP reclaim

long / short
Trigger
After a morning flush, price closes back above VWAP (VW marker) and the next bar holds.
Stop
Below the reclaim bar's low or the lower inner band.
Target
Upper inner band, then PDH or the outer band.
Short
Mirror image: VWAP lost and the retest fails.

Shannon, 2008 and 2023; Aziz, 2015

First pullback

trend
Context
Above VWAP, 9 EMA over 20, making higher highs. The dashboard Bias row is green.
Trigger
The first pullback to the 9 or 20 EMA on lighter volume; buy the break of the pullback's high.
Stop
Below the pullback low.
Target
Retest of the high, then a measured move equal to the first leg.

Aziz's bull flag; Brooks, 2011

Key-level break

gappers
Trigger
A close through PMH or PDH (PDH marker) with a full-color DT Volume bar.
Stop
Back inside the level, or the breakout bar's low.
Target
2R, then trail under the 9 EMA.
Skip
The break comes on faded volume: those fail more often.

Bellafiore, 2010; Aziz, 2015

Squeeze release

long / short
Context
DT Momentum on Squeeze, 5m or 15m, with a run of red dots.
Trigger
First green dot. Trade only in the histogram's direction, and only on the matching side of VWAP.
Stop
Other side of the coil, or 1.5 ATR.
Exit
When the histogram weakens for two bars in a row.

Carter, Mastering the Trade

Outer-band fade

advanced
Context
Range days only: RVOL fading below 1.5×, price chopping around a wide pivot range.
Trigger
2σ marker, then a reversal bar back inside the band.
Stop
Just beyond the extreme.
Target
Inner band, then VWAP. On a trend day, don't fade: the 2σ marker means don't chase.

Bollinger, 2001; Shannon, 2023

Risk

Risk rules

  • Define R firstR is entry minus stop. Size = dollars at risk ÷ R. DT Core's Long and Short rows do this division for the stop basis you pick (Tharp).
  • 0.5–1% per tradeElder's ceiling is 2% of the account per trade. Start at the low end while you learn the setups.
  • Daily stop at −3RHit it and you're done for the day. Elder's 6% rule does the same monthly: down 6% for the month, stop trading until next month.
  • Aim for 2RAziz looks for at least 2:1 reward to risk. With 2R winners, a 40% win rate is still profitable before costs.
  • Respect the clockNew ORB entries end at 11:30. Midday (shaded) volume is thin; size down or stand aside. Be flat before the close.
  • Journal every tradeA screenshot, the setup name, R result, and one sentence on execution. Steenbarger's point: review the process, not just the P&L.
  • Check your broker's rulesUS margin accounts face pattern-day-trader requirements. Confirm what applies to your account before trading live.
